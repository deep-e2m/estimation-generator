4. Required Technology Stack
Platform
• WordPress (latest stable version)
Theme & Blocks
• GeneratePress (Premium)
• GenerateBlocks (Pro)
Important Notes
• Use GenerateBlocks Pro Dynamic Fields where dynamic content is required
• Do not introduce additional page builders
Performance
• WP Rocket (no SiteGround or host-specific caching tools)
• Clean, minimal markup
• No unnecessary scripts, libraries, or bloat
5. Approved & Required Plugins
The following plugins are approved, expected, and will be used. No substitutes or additional plugins should be
introduced without approval.
Forms & CRM
• FluentForms Pro — all front-end forms
• FluentCRM Pro — CRM, contact management, and email campaigns
Forms must be properly connected to FluentCRM where applicable and styled to match approved designs.
Performance & Optimization
• WP Rocket — primary caching/performance plugin. Do not use SiteGround or host-level caching tools
• ShortPixel — image optimization
Security
• Solid Security Pro - Configure conservatively to avoid conflicts with forms and CRM
Content & Editorial
• Simple TOC - Used for table-of-contents generation on long-form blog posts
Admin Experience
• UIPress Pro - Used to create a custom WordPress dashboard and admin UI
Legal & Compliance
• Termageddon - Used for privacy policies, cookie policies, and legal pages
6. Development Standards
Block-First, Native WordPress
• All layouts must be built using:
o Core WordPress blocks
o GenerateBlocks only
• Create reusable blocks and patterns where appropriate
• Avoid custom PHP templates unless explicitly approved
Responsive Behavior
• Must match approved designs across:
o Large desktop
o Standard desktop/laptop
o Tablet
o Mobile
• No layout drift or breakpoint inconsistencies
CMS Usability
The finished site must allow RedWeb.Digital to:
• Edit copy safely without breaking layouts
• Swap images easily
• Add blog posts using predefined structures
• Preserve layout integrity through block locking where appropriate
7. Blog & Content Implementation
• Blog built using GenerateBlocks Elements & Query Loop
• Dynamic content handled via GenerateBlocks Pro Dynamic Data
• No custom post types unless explicitly requested
• No events, calendars, or event plugins
• Blog structure must be scalable without redesign
8. Performance Requirements
The completed site must:
• Load quickly on mobile and desktop
• Perform well in Google PageSpeed Insights
• Avoid render-blocking assets
• Use modern image handling
• Follow WordPress coding standards
This site serves as a reference build for RedWeb.Digital client work.
